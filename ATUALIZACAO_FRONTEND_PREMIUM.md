# Atualização Front-end Premium

Esta versão adiciona:

- Consentimento de cookies por dispositivo (essenciais, análise e marketing).
- Analytics condicionado ao consentimento.
- Preferências reabertas pelo rodapé.
- Toasts elegantes.
- Histórico de produtos vistos recentemente por dispositivo.
- Busca instantânea com miniaturas.
- Compartilhamento nativo no mobile / copiar link no desktop.
- Estados vazios premium.
- Pré-carregamento da próxima imagem das galerias.
- Fallback visual caso uma imagem falhe.
- Ajustes responsivos para os novos elementos.

Não requer SQL novo. Os dados de cookies, favoritos e vistos recentemente ficam no navegador do próprio visitante.

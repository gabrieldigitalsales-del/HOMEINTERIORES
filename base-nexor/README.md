# BASE NEXOR — reutilização

Esta pasta documenta o padrão para iniciar os próximos sites da NEXOR.

A ideia não é copiar a Home Interiores inteira. Reaproveite a arquitetura e adapte identidade, conteúdo e módulos do cliente.

Padrões obrigatórios: mobile-first, 404, SEO por rota, Open Graph, favicon, robots/sitemap, Privacidade/Termos, performance, acessibilidade básica, segurança de painel, CTAs rastreáveis, conteúdo editável e componentes reutilizáveis.

Para catálogos: multi-imagem, favoritos, orçamento, URL individual, status, rascunho/publicado, destaque, ordenação, relacionados, busca tolerante, compressão de imagem e WhatsApp contextual.
